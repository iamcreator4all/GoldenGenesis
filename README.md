# GoldenGenesis

Born from the timeless geometry of the Fibonacci spiral, **GoldenGenesis** translates mathematical harmony into a living desktop environment. The name itself reflects a genesis built on the golden ratio—where every curve, panel proportion, and transition flows with natural, organic precision.

## Palette
Infused with an uncompromising palette designed to bridge the gap between deep, moody sophistication and crisp modern usability:
* **Imperial Gold** (`#D4AF37`)
* **Deep Charcoal** (`#1A1917`)
* **Warm Ivory** (`#F8F6F0`)

## Installation
1. Ensure you have the **User Themes** GNOME Shell extension installed and enabled.
2. Extract `GoldenGenesis-Theme.tar.gz` into your local themes directory (`~/.themes/` or `~/.local/share/themes/`).
3. Apply the theme using the GNOME Extensions app or Tweaks.
